# Bosun app icon

`AppIcon-master.png` is the source image for the app icon. It was generated with an image-generation tool.

The design uses a dark navy tile, an ivory microphone and sound waves, and an amber accent. The standard macOS icon sizes are in `Resources/AppIcon.iconset`; the bundled icon is `Resources/AppIcon.icns`.

The menu bar uses native template symbols for listening and inactive states. Menu appearance follows macOS styling.
