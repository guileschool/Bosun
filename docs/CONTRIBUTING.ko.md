# 기여 안내

[English](../CONTRIBUTING.md)

새로운 기여자를 환영한다. 코드 작성 외에도 버그 제보, Mac에서의 음성 명령 테스트, 문서와 번역 개선으로 참여할 수 있다. 한국어와 영어 모두 가능하다.

## 처음 참여하기

1. 기존 Issues와 Pull Request에서 같은 작업이 있는지 확인한다. 큰 기능은 먼저 Issue에서 범위를 논의하고, 작은 수정은 바로 Pull Request로 제안해도 된다.
2. 저장소를 Fork하고 작업 브랜치를 만든다. 초대나 원본 저장소의 쓰기 권한은 필요하지 않다.
3. 한 가지 문제에 집중해 수정한다. 코드 변경은 아래 검사를 실행하고, 문서 변경은 링크와 한국어·영어 안내의 일치 여부를 확인한다.
4. 문제, 변경 내용, 검증 결과를 적어 Pull Request를 연다. 관리자가 검토한 뒤 반영한다.

음성 명령 문제는 macOS·Bosun 버전, 대상 앱, 명령어 모드, 예상·실제 동작, 짧은 받아쓰기와 긴 받아쓰기의 차이를 알려준다. 개인적인 발화 내용 없이 재현 절차를 작성한다. 실제 마이크 테스트와 자동 검사는 구분해서 기록한다.

## 개발 검사

macOS 14 이상과 Xcode Command Line Tools가 필요하다. 로컬 시험 빌드는 `SIGN_IDENTITY=- zsh build.sh`, 제출 전 검사는 `zsh scripts/test.sh`로 실행한다. 로컬 시험용 앱으로 기존 Developer ID 서명 설치본을 덮어쓰지 않는다.

손쉬운 사용 요소를 찾는 문자열은 번역된 메뉴 문자열과 분리한다. 명령어 안전 검사, 기기 내 음성 인식, 전사 삭제 결과 검증을 유지한다. 전사 처리 변경에는 회귀 테스트를 포함하고 한국어·영어 언어 파일을 함께 갱신한다.

Pull Request에는 사용자가 겪는 문제, 바뀐 동작, 검증 결과를 적는다. 로그에서 프롬프트·인식된 발화·개인 경로를 제거한다. 생성된 앱 번들이나 DMG를 소스로 제출하지 않는다.

## 문서 언어

기본 README는 영어이며 상단에 한국어 링크를 둔다. 설치·사용·문제 해결 안내는 한국어와 영어를 동등하게 유지하고 사용자 동작이 바뀌면 함께 갱신한다. 내부 개발 문서는 독자에게 적합한 언어를 사용해도 된다. 실시간 영어 지원을 보장하지 않는다.
