# Bosun 0.8.14

## English

Long dictation could leave a transcript in the input without sending: the microphone-stop transition had a fixed three-second timeout. Bosun now allows that transition to use the recording-based transcription budget and waits for both stable final text and a send-ready composer before removing the command and submitting.

- Keep the short timeout for recording startup and cancellation.
- Keep Break available during the extended wait; preserve input when readiness times out.
- Record failure codes and elapsed time to help diagnose unsuccessful sends.
- Include opt-in, text-free Record latency diagnostics.

The owner confirmed successful long-dictation sending with the fix before this release. Automated command and timing regression checks passed. This is not a claim that all voice commands or fresh installation on another Mac have been tested.

Apple Silicon · macOS 14+ · MIT. Download the DMG and optionally verify it with the accompanying SHA-256 file. Users of 0.8.13 can use Check for Updates; 0.8.12 and earlier need a one-time DMG replacement.

## 한국어

긴 받아쓰기 후 문장이 입력창에 남고 전송되지 않는 문제를 수정했다. 녹음 정지 상태 확인에 고정된 3초 제한을 적용하던 부분을 녹음 길이에 따른 전사 대기 시간으로 바꿨다. 최종 문장이 안정되고 보내기 가능한 상태가 된 뒤 명령어를 정리하고 전송한다.

- 녹음 시작·취소의 짧은 제한은 유지한다.
- 길어진 대기 중에도 Break로 중단할 수 있고 준비 상태 확인에 실패하면 입력을 유지한다.
- 전송 실패 코드와 경과 시간을 기록한다.
- 발화 내용을 기록하지 않는 선택적 Record 지연 진단 기능을 포함한다.

배포 전 수정본으로 긴 문장 전송이 성공한 것을 사용자가 확인했고, 자동 명령어·시간 지연 회귀 검사를 통과했다. 전체 음성 명령이나 다른 Mac에서의 새 설치를 모두 검증했다는 의미는 아니다.

Apple Silicon · macOS 14 이상 · MIT. DMG와 SHA-256 파일을 제공한다. 0.8.13은 업데이트 확인 메뉴를 사용할 수 있고 0.8.12 이하는 한 번 직접 앱을 교체해야 한다.
