# Bosun 사용 안내

[English](USAGE.md) · [개요](README.ko.md)

## 환경과 설치

macOS 14 이상인 Apple Silicon Mac을 사용한다. 기기 내 영어 음성 인식을 사용할 수 있어야 한다. [0.8.12 릴리스](https://github.com/guileschool/Bosun/releases/tag/v0.8.12)에서 개발자 서명과 Apple 공증을 마친 DMG를 다운로드한다. 저장소가 비공개인 동안에는 접근 권한이 필요하다.

DMG를 열고 Bosun을 Applications로 옮긴 뒤 실행한다. 메뉴 막대에 Bosun이 나타난다. 시스템 설정 → 개인정보 보호 및 보안에서 마이크, 음성 인식, 손쉬운 사용 권한을 허용한다. 업데이트는 같은 개발자 서명의 앱을 사용해 기존 권한을 유지한다.

소스에서 시험 빌드하려면 개요의 빌드 안내를 따른다. 임시 서명 시험용 앱으로 개발자 서명이 적용된 설치본을 덮어쓰지 않는다.

## 처음 사용하기

1. 제어할 ChatGPT 데스크톱 입력창을 연다.
2. 메뉴 막대에서 Bosun을 열고 음성 감지를 시작한다.
3. 영어 받아쓰기에는 복합어 모드를 선택한다. 메뉴 언어와 명령어 모드는 별도 설정이다.
4. “Record, please”라고 말하고 짧은 문장을 말한 뒤 “Stop, please”라고 말한다. 녹음이 멈추고 입력창에 글이 남는지 확인한다.
5. 전송 전에 내용을 확인한다. “Send, please”는 녹음을 마치고 말끝 명령어를 정리한 뒤 입력 내용을 전송한다.

“Cancel, please”는 받아쓰기를 취소한다. “Break, please”는 진행 중인 전송 절차나 응답 생성을 중단하며, 이미 보낸 메시지를 회수하지 않는다. 나머지 명령어는 개요에 정리했다. Undo는 같은 입력창의 내용이 그대로일 때 직전 Bosun Delete 또는 Clear를 한 번 복원한다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 명령어를 감지하지 못함 | 음성 감지, 마이크 권한, 선택한 명령어 모드와 실제 발화가 맞는지 확인한다. |
| 명령어는 감지하지만 동작하지 않음 | 손쉬운 사용 권한과 제어하려는 입력창을 확인한다. |
| 녹음이 멈추지 않음 | 대상 앱의 정지 버튼으로 멈춘 뒤 Bosun 진단 메뉴를 확인하고 문제를 제보한다. |
| 전사가 전송되지 않음 | 입력 내용과 오류를 확인하고, 이미 전송되지 않았는지 확인한 뒤 재시도한다. |
| Undo가 동작하지 않음 | 입력이 그대로일 때 Bosun의 직전 Delete 또는 Clear만 복원한다. |
| 업데이트 후 문제 발생 | 권한과 Applications 설치 위치, 개발자 서명이 유지됐는지 확인한다. |

Option 키를 누른 채 Bosun 메뉴를 열면 진단 항목이 나타난다. 진단에는 인식한 말이나 입력 내용이 포함될 수 있으므로 개인 내용을 지운 최소한의 예시만 공유한다. 대상 앱의 화면 변경은 자동화에 영향을 줄 수 있다. [현재 검증 범위](VALIDATION.md)를 참고한다.

## 질문과 오류 제보

저장소의 Issues를 사용할 수 있을 때 질문이나 오류를 등록한다. 한국어·영어 모두 접수하며 실시간 영어 지원은 약속하지 않는다. Bosun 버전, macOS 버전, 대상 앱 이름·버전과 화면 언어, 명령어 모드, 실제로 말한 명령어, 기대 결과와 실제 결과를 적는다. 인증 정보나 개인 대화 내용은 포함하지 않는다.

Bosun을 사용하기 위해 채널 구독이나 구매를 할 필요는 없다.
